# Portrait

A profile of you drawn from your own notes: interests, projects, habits and open questions.

A brain app for [BRAINF](https://github.com/gregorygerman777-hub/BRAINF). It runs as a tab
(`/portrait`) inside your brain and talks to it through the console's app bridge.

- Permissions: `llm.invoke`
- Memory layers: episodic (read), semantic (read)

## Install

In your brain: **Settings > Apps**, paste
`https://github.com/gregorygerman777-hub/brain-app-portrait` and approve.

## Files

- `brain-app.yaml`: the manifest (`brain-app/v1`)
- `dist/index.html`: the whole app, no build step
